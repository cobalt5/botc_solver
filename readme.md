# Blood On The Clocktower solver

A solver for the popular board game [blood on the clockotwer](https://bloodontheclocktower.com/). It uses a formal logic structure, combined with a UI and a solver utilizing [Google's CP-SAT solver](https://developers.google.com/optimization/cp/cp_solver) to solve games when players have no idea what's going on!

## Status
The formal logic structure is defined in [situations.md](situations.md), it can now fully describe any game of the base script [Trouble Brewing](https://wiki.bloodontheclocktower.com/Trouble_Brewing). The UI and solver programs are a work in progress.
